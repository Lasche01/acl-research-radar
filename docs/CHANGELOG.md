# 변경 이력

## v0.7.1 — 미사용 코드와 공개 문서 정리

- 현재 실행 경로에서 사용하지 않는 Ollama 연결·임베딩·로컬 AI 판정 코드를 제거했습니다. 기본 규칙 모드와 선택형 GPT API 모드는 유지합니다.
- 구형 일괄 수집 함수를 제거하고, 관련 회귀 시험 6개를 실제 앱에서 사용하는 마감·제목 선별 및 재개 대기열 경로로 옮겼습니다.
- 미사용 import와 객체를 제거하고, 초기 불완전 JSON 예제를 실행 가능한 합성 데모로 통일했습니다.
- 화면 하단 버전은 서버가 반환하는 버전으로 갱신합니다. GPT 자격 판정에 ‘규칙 심사’라고 표시하던 공통 문구도 ‘원문 근거 있음’으로 정리했습니다.
- 공개 점검 문서에서 내부 업로드·승인 경위를 덜어내고, 합성 스크린샷의 포함 범위를 명시했습니다. 구버전 변경 기록을 이 문서로 모았습니다.
- Python 시험 252개를 통과했습니다. v0.7.0의 255개 중 제거한 로컬 AI 기능 전용 시험 3개를 정리한 차이이며, GPT의 인용·경로 검증과 오류 시 보류 시험은 유지합니다.

## v0.7.0 — 선택형 GPT API 심사

- 명시적으로 실행하는 OpenAI Responses API 모드를 연결했습니다. 기본 실행은 API 없는 규칙 모드입니다.
- 구조화된 판정·원문 인용·연구실 실적 연결을 받고, 인용과 활성 그래프 경로·날짜를 프로그램에서 검증합니다.
- 모드·모델·원문·프로필별 결과 재사용, 작업별 호출 상한, 오류·거절·근거 실패 시 보류를 적용했습니다.
- API 통합은 모의 응답으로 시험했습니다. 실제 Key를 사용한 유료 호출과 추천 성능은 미검증입니다.

## v0.6.0 — 규칙 심사의 문맥·자격·문서 역할 보완

- 연구 목표에 ‘공고’가 포함된 표현, 표의 줄 분리와 한글 띄어쓰기·약어 조사를 처리했습니다.
- 대학 신청 자격과 기업의 보증보험 면제 등 부가 조건을 구분하는 규칙을 보강했습니다. 가점 문구 일부의 오인은 이후 실제 진단에서도 남아 있었습니다.
- 핵심 RFP·공고문과 매뉴얼·서식·참고 법령의 역할, 직접 연구 주제 대응과 인접 기술 관계를 구분했습니다.
- 연구 적합도와 신청 조건을 분리하고, 자격 등이 미확인인 관련 후보를 보존했습니다.
- 진단에 짧은 원문 인용·출처 문서·보류 이유를 추가했습니다. 기관별 링크 추출 미지원과 실제 RFP 자격 확인을 모두 해결한 버전은 아닙니다.

실제 운영 결과와 알려진 한계는 [개발 사례](CASE_STUDY.md), 현재 시험 범위는 [검증 기록](VALIDATION.md)에 정리했습니다.
