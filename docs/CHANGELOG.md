# 변경 이력

## v0.7.1 — 미사용 코드와 문서 정리

- 사용하지 않는 Ollama 연결·임베딩·로컬 AI 판정 코드와 구형 일괄 수집 함수를 제거했습니다.
- 수집 테스트 6개를 현재 앱의 마감·제목 선별 및 재개 대기열 경로로 옮겼습니다.
- 미사용 import·객체와 불완전한 JSON 예제를 정리하고, 실행 가능한 가상 공고 데모를 남겼습니다.
- 화면 하단 버전을 서버의 버전 값으로 갱신하고, GPT 자격 판정에 표시하던 ‘규칙 심사’를 ‘원문 근거 있음’으로 수정했습니다.
- 공개 점검 문서와 변경 기록을 정리했습니다.
- 자동화 테스트 252개를 통과했습니다. 제거한 로컬 AI 기능의 전용 테스트 3개를 정리한 결과입니다.

## v0.7.0 — GPT로 공고를 검토하는 모드 추가

- OpenAI Responses API를 이용한 검토 모드를 추가했습니다. 실행할 때 규칙 모드와 GPT 모드를 선택할 수 있습니다.
- GPT가 반환한 인용문을 원문과 대조하고, 등록된 실적과 주제의 연결 및 마감일을 확인하도록 구현했습니다.
- 완료 결과 재사용, 작업별 호출 한도, API 오류와 답변 검증 실패 시 보류 처리를 추가했습니다.
- API 연동을 모의 응답으로 테스트했습니다. 실제 API 호출과 추천 성능 평가는 추가 확인 항목입니다.

## v0.6.0 — 연구 내용·자격·첨부 처리 개선

- 연구 목표에 ‘공고’가 포함된 문장, 표의 줄 분리, 한글 띄어쓰기와 약어 조사를 처리하는 규칙을 보강했습니다.
- 대학 신청 자격과 기업의 보증보험 면제 등 부가 조건을 구분하도록 수정했습니다. 일부 가점 문구의 오인은 이후 실행에서도 발견됐습니다.
- 공고문·RFP와 매뉴얼·서식·참고 법령의 오류를 구분하고, 직접 연구 주제와 인접 기술의 연결을 따로 표시했습니다.
- 연구 관련성과 신청 조건을 분리해 관련 후보를 보관했습니다.
- 진단에 짧은 원문 인용·출처 문서·보류 이유를 추가했습니다. 기관별 링크 추출과 실제 RFP 자격 확인은 추가 개선 항목으로 남았습니다.
