프로그램 버전별 기능·코드·테스트 변경을 기록합니다. 현재 사용 방법은 [사용 가이드](USAGE.md), 구체적인 오류와 수정 과정은 [개발 사례](CASE_STUDY.md)를 참고하세요.

## v0.7.1

### 정리

- 사용하지 않는 Ollama·임베딩·로컬 AI 판정 코드와 구형 일괄 수집 함수를 제거했습니다.
- 미사용 import·객체와 불완전한 JSON 예제를 정리하고 실행 가능한 가상 공고 데모를 남겼습니다.
- 공개 점검 문서와 변경 기록을 정리했습니다.

### 수정

- 수집 테스트 6개를 현재 앱의 마감·제목 선별과 재개 대기열 경로로 옮겼습니다.
- 화면 하단 버전을 서버의 버전 값으로 갱신합니다.
- GPT 자격 판정의 ‘규칙 심사’ 문구를 ‘원문 근거 있음’으로 수정했습니다.

### 검증

Python 테스트 252개를 통과했습니다. 제거한 로컬 AI 기능의 전용 테스트 3개를 정리해 v0.7.0의 255개에서 줄었습니다.

## v0.7.0

### 추가

- OpenAI Responses API를 사용하는 GPT 검토 모드를 추가했습니다.
- 인용문과 원문, 등록된 실적·주제 연결과 마감일을 확인합니다.
- 완료 결과 재사용, 작업별 호출 한도, API·답변 검증 오류 시 보류 처리를 적용했습니다.

### 검증

API 연동은 모의 응답으로 테스트했습니다. 실제 호출과 추천 성능 평가는 추가 확인 항목입니다.

## v0.6.0

### 개선

- 연구 목표에 ‘공고’가 포함된 문장, 표 줄 분리, 한글 띄어쓰기와 약어 조사 처리
- 대학 신청 자격과 기업 보증보험 면제 등 부가 조건 구분
- 공고문·RFP와 매뉴얼·서식·참고 법령의 오류 구분
- 직접 연구 주제와 인접 기술의 연결 표시
- 연구 관련성과 신청 조건을 분리하고 관련 후보 보관
- 진단에 원문 인용·출처 문서·보류 이유 추가

### 추가 확인

일부 가점 문구의 오인은 이후 실행에서도 발견됐습니다. 기관별 링크 추출과 실제 RFP의 자격 대조도 추가 개선 항목으로 남았습니다.
