# 공개 자료 점검

v0.7.1 공개 소스의 파일 목록과 인증정보 패턴, 예제·이미지 출처를 2026-11-09에 확인했습니다.

## 포함한 자료

- Python·웹 UI 소스, 실행·설정 스크립트, 선택 의존성 목록
- 공개 기관 경로와 연구 주제·실적의 초기 메타데이터
- 합성 회귀 시험, 실행 가능한 데모, 검증 로그와 개발 설명
- `docs/images/`의 합성 공고 데모 스크린샷 2장. 실제 앱을 기본 규칙 모드로 실행한 화면이며 실제 공고·개인 데이터·GPT 실호출 결과가 아닙니다. [촬영 범위와 재현](SCREENSHOTS.md)

## 제외한 자료

- 실제 API Key·토큰·로그인 정보·개인 키·사용 환경 파일
- 실행 DB·백업·수집 진단 원본·실제 공고 첨부·캡처·개인 판단 기록
- 비공개 연구 자료·대화 로그·채용 안내 이미지·빌드 ZIP·캐시

빈 변수의 `.env.example`은 설정 설명용으로 포함합니다. 합성 시험의 가짜 Key 문자열과 환경변수 이름을 실제 인증정보와 구분했습니다. 공개 연구 프로필에서는 계정 식별 쿼리가 있던 개별 URL을 제외했습니다.

## 확인 범위

공개 대상 파일과 링크를 대조하고, API·클라우드 Key와 토큰·개인 키 형식, 이메일·계정 식별 쿼리·개인 로컬 경로를 점검했습니다. 스크린샷은 합성 예제의 실제 UI이며 사용자 DB를 사용하지 않습니다. 이번 정리로 과거 커밋이나 GitHub 작성자 메타데이터를 삭제한 것은 아닙니다.

`.gitignore`는 향후 실수로 추가하는 것을 줄이는 보조 장치이며, 이미 커밋된 정보를 삭제하지 않습니다. 공개 데이터는 개인 개발 증빙용이고 연구실·기관의 공식 서비스나 비공개 사업 성과로 표시하지 않습니다.
