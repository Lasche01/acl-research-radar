# 공개 전 점검

v0.7.1 공개 파일을 기준으로 소스·예제·이미지의 내용과 출처를 2026-11-09에 점검했습니다.

## 공개한 자료

- Python·웹 UI 소스와 실행·설정 스크립트
- 공개 기관의 공고 경로와 연구 주제·실적 정보
- 가상 공고, 자동화 테스트, 테스트 로그와 개발 문서
- 기본 규칙 모드로 촬영한 가상 공고 스크린샷 2장

스크린샷의 데이터와 실행 방법은 [데모 문서](SCREENSHOTS.md)에 정리했습니다.

## 공개에서 제외한 자료

- 실제 API Key·토큰·로그인 정보·개인 키·사용 환경 파일
- 실행 DB·백업·수집 진단 원본·실제 공고 첨부·개인 판단 기록
- 비공개 연구 자료·대화 로그·채용 안내 이미지
- 빌드 ZIP과 캐시

[.env.example](../.env.example)은 빈 변수로 작성한 설정 예시입니다. 테스트 코드에는 가짜 Key 문자열을 사용했습니다. 공개 연구 프로필에서는 계정 식별 쿼리가 들어 있던 개별 URL을 제외했습니다.

## 확인한 항목

공개 파일에서 인증정보 형식, 이메일·계정 식별 쿼리와 개인 로컬 경로를 검색하고, 발견된 항목의 용도를 확인했습니다. 문서 링크와 데모 이미지의 출처도 함께 점검했습니다.

환경 파일과 실행 데이터는 [.gitignore](../.gitignore)의 제외 대상입니다. 이미 커밋한 민감정보를 발견하면 파일 삭제와 별도로 Git 이력을 정리해야 합니다.
