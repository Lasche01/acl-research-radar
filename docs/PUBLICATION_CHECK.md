# 공개 전 점검 기록

공개용 v0.7.0 사본에 대해 2026-11-09에 아래 범위를 확인했습니다. 보안 인증이나 모든 가능한 비밀정보의 부재를 보증하는 보고서가 아니라, 이번 공개에 실제로 적용한 점검 범위입니다.

## 공개에 포함한 자료

- Python·로컬 웹 UI 소스, 합성 테스트, 공개 출처 목록과 연구 메타데이터
- 개발 사례·역할 구분·검증 방법·실행 로그
- 실행 스크립트와 선택 의존성 목록

## 공개에서 제외한 자료

- 사용자 실행 DB, 백업, 수집 진단 원본, 실제 공고 첨부·캡처·다운로드 파일
- 실제 API Key·토큰·로그인 정보·환경 파일·키 파일. 빈 변수의 `.env.example`만 설명용으로 포함합니다.
- 채용 안내 이미지, 대화 로그, 개인 피드백과 비공개 연구 자료
- 빌드 산출물, wheel/ZIP, 로컬 캐시

초기 공개 연구 프로필의 계정 식별 쿼리가 들어 있던 개별 교원정보 URL을 공개 사본에서 제거했습니다. 연구 주제·실적 노드와 연결은 유지했습니다. 일반적인 기관 공고 번호·메뉴 번호는 공개 출처 식별값으로 유지했습니다.

## 확인한 항목

1. 공개 대상 파일을 소스·문서·합성 예제의 명시적 목록으로 구성.
2. API Key·GitHub 토큰·클라우드 키·개인 키 형식, 이메일 주소, 계정 식별 쿼리, 개인 로컬 경로 패턴 점검.
3. 탐지된 `/home/…` 문구는 기관 웹사이트의 공개 라우트·링크 해석 정규식·테스트 URL임을 대조.
4. 인증정보 이름을 참조하는 환경변수와 합성 테스트 문자열을 실제 인증정보와 구분. 실행에 실제 Key를 넣지 않음.
5. 사용자 DB·진단·원문·이미지·바이너리가 파일 목록에 없는지 점검.
6. GitHub 공개 상태와 공개된 커밋의 파일·메타데이터를 업로드 후 확인. 최종 확인 결과는 저장소의 실제 커밋과 공개 조회 결과로 대조.

`.gitignore`는 향후 실수로 추가하는 것을 줄이기 위한 보조 장치입니다. 이미 커밋된 비밀정보를 삭제해 주는 기능이 아니므로, 이번 공개에서는 파일 목록 자체를 점검합니다. 과거 개발 중 개인 데이터가 들어 있을 수 있는 로컬 이력을 가져오지 않으며, 버전 이력을 과거 날짜의 커밋으로 재구성하지 않습니다.

## 열람과 역할

이 저장소는 개인 개발 증빙용 공개 소스입니다. 연구실·기관의 공식 서비스 또는 비공개 사업 성과로 표시하지 않습니다. AI 코딩 지원과 사용자의 요구사항·검토 역할은 [개발 과정](DEVELOPMENT.md)에 명시했습니다. 실제 운영 데이터 대신 [합성 재현 예제](../examples/verify_evidence.py)를 제공합니다.

## 커밋 작성자 메타데이터

GitHub 연결 도구는 계정의 기본 이메일을 작성자·커미터 메타데이터에 기록합니다. 사용자가 2026-11-09 공개를 허용했으며 초기 README 커밋을 유지하고 소스 업로드를 진행합니다. 주소 자체를 문서에 추가하지 않습니다. 작성자 계정 메타데이터까지 제거한 익명 저장소라고 주장하지 않습니다.

로컬 준비본의 Git 작성자·커미터는 noreply 형식입니다. 로컬 준비 이력으로 원격 이력을 덮어쓰지 않습니다. 실제 API Key를 사용하지 않고 합성 Key와 모의 응답으로 API 동작을 시험했습니다.
