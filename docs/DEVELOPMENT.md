# 개발 과정과 역할

이 프로젝트는 AI 코딩 지원을 사용해 개발한 개인 프로젝트입니다. v0.6.0까지의 기본 실행 경로는 규칙 기반입니다. v0.7.0은 사용자가 명시적으로 실행하는 GPT API 심사 모드를 추가했습니다. 개발 과정의 AI 지원과 프로그램 실행 중 GPT의 의미 심사를 구분합니다.

| 역할 | 실제 수행 내용 |
|---|---|
| 사용자 | 문제·대상 연구 분야 정의, 연구실 실적 기반 연결 요구, 마감 우선→제목 선별→상세 우선순위 요구, 실제 Windows 실행, 오류 화면·진단 제공, 보류 사유와 추천 결과 검토, 수정 방향 결정 |
| AI 코딩 지원 | Python·웹 UI 구현, 수집·문서 추출·규칙 설계안 작성, 테스트 및 배포 자료 생성, 제공된 오류·진단과 코드 대조 지원 |
| 함께 검증한 과정 | 오탐과 추천 0건 원인 구분, 합성 사례로 판정 오류 재현, 예외 규칙 수정 후 회귀 시험, 실제 진단에서 잔여 오류 확인 |

모든 코드를 사용자가 직접 타이핑했다고 주장하지 않습니다. 255개 시험 통과를 실제 사업공고 추천 정확도로 바꾸어 표현하지 않습니다. API 연동 시험은 모의 응답으로 수행했으며 실제 유료 호출은 아직 수행하지 않았습니다. 공개 목록에 없는 비공개 실적이나 기관 승인·공식 수행 이력을 주장하지 않습니다.

런타임의 GPT는 공고·RFP와 공개 연구 프로필을 대조해 판정·인용·연결을 반환합니다. 프로그램은 원문 인용과 기존 그래프 경로를 검사하고, 사용자는 최종 판단을 합니다. [AX 처리 흐름](GPT_API.md)에 요청·검증·실패 처리와 전송 범위를 공개했습니다.

공개 자료에는 계정별 실행 원문·개인 판단·채용 안내 화면·대화 로그를 포함하지 않았습니다. 공개 저장소 생성 시점부터의 커밋만 실제 공개 이력으로 남깁니다.
