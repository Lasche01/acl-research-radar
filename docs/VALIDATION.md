## 테스트 방법

PDF 추출 테스트에 필요한 의존성을 먼저 설치합니다.

```bash
python -m pip install -r requirements-optional.txt
```

다음 테스트는 실제 기관 사이트와 OpenAI API 호출 없이 실행합니다.

```bash
python -m unittest discover -s tests -q
node --check aclbrief/static/app.js
node tests/test_ui_filters.js
python examples/verify_evidence.py
python examples/verify_gpt_workflow.py
```

## 확인한 동작

| 기능 | 테스트 내용 |
|---|---|
| 수집 순서 | 마감 공고의 상세 요청 생략, 제목별 선별, 기간 미확인 시 첨부 보류 |
| 수집 재개 | 반복·빈 목록 처리, 중지·재개, 여러 작업의 중복 실행 방지 |
| 문서 처리 | 핵심 RFP와 매뉴얼의 오류 구분, ZIP 문서 추출, 큰 문서와 수동 보완 자료 보존 |
| 연구 연결 | 표현 변화·표 줄 분리·한글 조사 처리, 비활성 주제 제외, 원문 인용과 실적 연결 확인 |
| 신청 자격 | 대학 허용·제한, 기업 부가 혜택, 필수 컨소시엄, 법령 참조와 조건 충돌 처리 |
| 화면 | 추천·관련 후보·검토 대기·제목 미선별 필터, 선택한 검토 모드와 요청 횟수 표시 |
| GPT 요청 | 명시적 모드 선택, 작업별 호출 한도, 완료 결과 재사용, 모드·모델 변경 후 재분석 안내 |
| GPT 오류 | 연결·형식·인용·그래프 오류 시 보류, Key와 오류 본문의 비저장 |
| 네트워크 | 기본 규칙 모드의 AI 미호출, 공개 주소와 TLS 인증서 확인 |

v0.7.1에서는 구형 수집 함수의 테스트 6개를 현재 수집 경로로 옮겼습니다. 제거한 로컬 AI 기능의 전용 테스트 3개를 정리해, v0.7.0의 255개에서 252개가 됐습니다. GPT API 통합 테스트 24개와 인용·연결 확인 테스트는 유지합니다.

## 추가로 확인할 내용

- 실제 API 호출과 모델별 추천 정확도·비용·속도
- 정답을 붙인 실제 공고를 이용한 정밀도·재현율과 업무시간 절감 효과
- 기관별 최신 페이지와 첨부 수집 성공률
- 수중 통신 과제 원문에 적힌 대학 신청 자격
- 이미지·수식·도표의 판독
- Windows/Python 3.14에서 최신 버전 실행과 전체 브라우저 화면 확인

GPT API 연동은 모의 응답으로 테스트했습니다. 실제 실행에서 발견한 가점 문구와 연구 목표 추출 오류는 [개발 사례](CASE_STUDY.md#실행-결과)에 정리했습니다.
