# 검증 기록

## 환경과 실행

- 공개 검증 시점: 2026-11-09, v0.7.0
- 로컬 환경: Python 3.12/Linux, Node.js
- 검증 명령: 아래 명령은 사용자 DB와 실제 기관의 네트워크 없이 실행합니다.

```bash
python -m pip install -r requirements-optional.txt
python -m unittest discover -s tests -q
node --check aclbrief/static/app.js
node tests/test_ui_filters.js
python examples/verify_evidence.py
python examples/verify_gpt_workflow.py
```

v0.7.0의 unittest 255개를 통과했습니다. 기존 231개 시험에 API 모드 통합 시험 24개를 추가했습니다. API 응답은 모의 객체로 대체하며 실제 유료 호출은 없습니다. 결과는 [실행 로그](validation-log.txt)에 기록합니다. Windows 네이티브 BAT·실사이트 전수 검증 결과가 아닙니다.

## 검증하지 않은 것

- 실제 공고의 정밀도·재현율·업무시간 절감률
- 실제 Key를 사용한 유료 API 호출·모델별 의미 판단 정확도·비용·속도
- 모든 기관의 최신 HTML·동적 목록·첨부 수집 성공률
- 실제 수중 통신 과제의 대학 신청 자격 확정
- 이미지·수식·도표의 완전한 해석
- Windows/Python 3.14 네이티브 실행 및 전체 브라우저 시각 검증

실제 진단에는 알려진 가점 조건 오인과 연구 문맥 추출 문제가 남아 있습니다. [개발 사례](CASE_STUDY.md)에 공개했습니다.
