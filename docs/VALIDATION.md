## 시작 전 준비

Python, Node.js와 프로젝트 소스가 필요합니다. PDF 테스트용 의존성을 설치합니다.

```bash
python -m pip install -r requirements-optional.txt
```

## 1. 자동 검사 실행

```bash
python -m unittest discover -s tests -q
node --check aclbrief/static/app.js
node tests/test_ui_filters.js
```

**확인:** Python 테스트가 완료되고 JavaScript 문법·UI 필터 검사가 오류 없이 끝나는지 확인하세요.

## 2. 가상 공고와 모의 응답 확인

```bash
python examples/verify_evidence.py
python examples/verify_gpt_workflow.py
```

첫 예제는 문장 표현·신청 자격·부가 혜택이 규칙 결과에 미치는 영향을 보여줍니다. 두 번째 예제는 정상 인용의 통과, 만들어 낸 인용의 보류, 자격 미확인 후보의 보관을 확인합니다. 실제 기관·OpenAI API 호출은 차단합니다.

## 테스트 범위

| 기능 | 확인하는 동작 |
|---|---|
| 수집 순서 | 마감 공고 상세 요청 생략, 제목별 선별, 기간 미확인 시 첨부 보류 |
| 수집 재개 | 반복·빈 목록 처리, 중지·재개, 중복 작업 방지 |
| 문서 처리 | 핵심 RFP·매뉴얼 오류 구분, ZIP 추출, 큰 문서·수동 보완 자료 보존 |
| 연구 연결 | 표현 변화·표 줄 분리·한글 조사, 비활성 주제 제외, 원문 인용·실적 연결 |
| 신청 자격 | 대학 허용·제한, 기업 부가 혜택, 컨소시엄, 법령 참조와 조건 충돌 |
| 화면 | 추천·후보·검토 대기·제목 미선별 필터, 검토 모드와 요청 횟수 표시 |
| GPT 요청 | 명시적 모드 선택, 작업별 호출 한도, 완료 결과 재사용, 변경 후 재분석 |
| GPT 오류 | 연결·형식·인용·그래프 오류 시 보류, Key·오류 본문의 비저장 |
| 네트워크 | 기본 규칙 모드의 AI 미호출, 공개 주소·TLS 인증서 확인 |

v0.7.1에서는 수집 테스트 6개를 현재 경로로 옮기고 제거한 로컬 AI 기능의 전용 테스트 3개를 정리했습니다. Python 테스트 수는 v0.7.0의 255개에서 252개가 됐습니다. GPT 통합 테스트 24개와 인용·연결 확인 테스트는 유지합니다.
