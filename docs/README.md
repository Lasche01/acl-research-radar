# 문서 안내

이 문서는 ACL Research Radar의 사용·개발·테스트 가이드를 안내합니다. 처음 실행한다면 [빠른 시작](../README.md#빠른-시작), 실행 중 문제가 있다면 [문제 해결](TROUBLESHOOTING.md)부터 확인하세요.

## 사용 가이드

| 문서 | 다루는 내용 |
|---|---|
| [사용 방법](USAGE.md) | 실행 환경, 업데이트, 수집 순서, 결과 확인, 직접 확보한 자료 가져오기 |
| [GPT 설정](GPT_API.md) | 모델·API Key, 요청 한도, 원문과 답변을 확인하는 과정 |
| [데모](SCREENSHOTS.md) | 가상 공고 실행과 README 화면 재현 |
| [문제 해결](TROUBLESHOOTING.md) | 증상별 진단과 조치 |

처음 사용하는 경우 **사용 방법 → 규칙 모드 실행 → 데모 또는 실제 수집** 순서로 진행하세요. GPT를 사용하려면 그다음 GPT 설정을 적용합니다.

## 개발·검토 가이드

| 문서 | 다루는 내용 |
|---|---|
| [개발 가이드](DEVELOPMENT.md) | 구성 요소, 데이터 흐름, 수정 위치와 테스트 명령 |
| [테스트 기록](VALIDATION.md) | v0.7.1 테스트 결과와 추가 확인 항목 |
| [개발 사례](CASE_STUDY.md) | 오탐·누락을 확인하고 수정한 과정, 역할과 AI 활용 |
| [변경 이력](CHANGELOG.md) | 버전별 추가·수정·정리 내용 |
| [공개 전 점검](PUBLICATION_CHECK.md) | 공개 파일의 범위와 민감정보 점검 |

개발 증빙을 검토한다면 **개발 사례 → 테스트 기록 → 관련 소스** 순서로 읽을 수 있습니다.

## 문서와 기록의 구분

- 사용·설정 문서는 현재 v0.7.1 동작을 설명합니다.
- README 이미지는 v0.7.0에서 촬영한 규칙 모드의 가상 공고 데모입니다.
- `validation-log.txt`는 v0.7.1 코드 테스트의 실행 출력을 보관합니다.
- 프로그램·환경변수·JSON 필드 이름은 코드와 같은 표기를 사용합니다.

문서의 역할 구분, 단계별 절차와 확인 방법은 [awslabs/aidlc-workflows의 문서 구성](https://github.com/awslabs/aidlc-workflows)을 참고했습니다.
